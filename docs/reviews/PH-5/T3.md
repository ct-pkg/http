## 为什么没有红

E-P5-3 在 T2 落地时就已被满足：`real_send` 把传输结果直接写进 `error`
（`resp->error = transport`），没有「已知码表」这道会吞掉未知值的分支，
`error_stage` 的 default 只影响文案，不影响数值。因此本夹具在 T2 的基线上
第一次运行就是绿的：

```console
$ bash test/run.sh p5-unknown
ok p5-unknown
rc=0
```

不伪造红：没有先把实现改成「未知码归零」再修回来，那只是制造一次假失败。
本任务因此只提交补充断言，没有独立的 `feat` 提交；偏差记入
`docs/phases/PH-5/closeout.md` §4。
