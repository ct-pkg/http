# PH6-T5 红证：负超时是本地错误

- baseline: `1efd26a`（PH6-T4 实现）
- 夹具: `test/fixtures/p6-negative.c` + expected
- 目的: `idle_timeout(-1)` 与 `timeout(-1)` 都必须读 `-1005`，且请求不离开进程
  （服务端计数 0）。

## 红

```console
$ bash test/run.sh p6-negative
--- expected
+++ actual
@@ -1 +1 @@
-idle -1005 timeout -1005 requests 0
+idle 0 timeout -1005 requests 1
FAIL p6-negative: output mismatch
rc=1
```

行为红：T3/T4 的 `idle_timeout` 只存值不校验，负值被当成「无限制」，请求真的
发了出去（`requests 1`）。

## 转绿

实现提交 `feat(http): PH6-T5 负超时` 后：

```console
$ bash test/run.sh p6-negative
ok p6-negative
rc=0
```

green: 输出 `idle -1005 timeout -1005 requests 0`。转绿提交 sha 见
`docs/phases/PH-6/closeout.md` §2。
