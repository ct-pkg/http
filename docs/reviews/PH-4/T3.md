# PH4-T3 红证：`take_body` 单所有权

- baseline: `876f317`（PH4-T2 实现）
- 夹具: `test/fixtures/p4-take-body.c`（ASAN 正例）、`p4-take-body-bad.c`（ASAN 负例）
- 目的: 取走 body 后原响应不再持有它，释放响应再释放取走的指针在 ASAN 下 0 报错。
  这是用例证明，不是代码审查；负例证明 ASAN 真的会抓 double-free。

## 红

```console
$ bash test/run.sh p4-take-body
test/fixtures/p4-take-body.c:24:18: error: call to undeclared function 'http_response_take_body'
test/fixtures/p4-take-body.c:24:11: error: incompatible integer to pointer conversion initializing 'char *'
FAIL p4-take-body: cc -fsanitize=address failed
rc=1
```

负例在红状态下已经是绿的，这是预期的：它不调用 `take_body`，只用现有 API 复现
「保留 body 指针 → 释放响应 → 再释放旧指针」的 double-free，用来证明 ASAN 断言
不是空转。红由正例承担。

```console
$ bash test/run.sh p4-take-body-bad
ok p4-take-body-bad (ASAN rejected the stale pointer)
rc=0
```
