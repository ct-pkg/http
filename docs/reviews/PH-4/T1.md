# PH4-T1 红证：`send()` 真执行

- baseline: `269e688`（PH-4 卡与判据冻结）
- 夹具: `test/fixtures/p4-server.h`、`p4-server.c`、`p4-status.c` + `p4-status.expected.out`；既有 `phase1_abi.c`、`phase1_chain.ct`、`phase1_var.ct`、`p2-after-send.ct`、`p3-chain.ct` 适配

所以这条判据在实现前必然是红的。
