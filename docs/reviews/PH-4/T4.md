# PH4-T4 红证：失败码可观察

- baseline: `a1fb667`（PH4-T3 实现）
- 夹具: `test/fixtures/p4-refused.c`、`p4-timeout.c` + expected
- 目的: 真执行的失败侧也要能核对，而不是只看成功时返回 200。拒绝连接是 7，
  总超时是 28；两者经 `http_shim_last_curl_code()` 观察。这个钩子只给测试用，
  不是公开错误面（PH-5 决定）。

## 红

```console
$ bash test/run.sh p4-refused
test/fixtures/p4-refused.c:17:12: error: call to undeclared function 'http_shim_last_curl_code'
1 error generated.
FAIL p4-refused: cc failed
rc=1

$ bash test/run.sh p4-timeout
test/fixtures/p4-timeout.c:25:12: error: call to undeclared function 'http_shim_last_curl_code'
1 error generated.
FAIL p4-timeout: cc failed
rc=1
```

## 转绿

实现提交 `feat(http): PH4-T4 失败码可观察` 后：

```console
$ bash test/run.sh p4-refused
ok p4-refused
$ bash test/run.sh p4-timeout
ok p4-timeout
rc=0
```

green: `p4-refused` 输出 `status 0 code 7`；`p4-timeout` 输出 `status 0 code 28`。
两种超时（连接/总时长）在 libcurl 侧都落到 `CURLE_OPERATION_TIMEDOUT`，调用方
拿不到区分信息——这条事实按卡 §9.5 写进收口。转绿提交 sha 见
`docs/phases/PH-4/closeout.md` §2。
