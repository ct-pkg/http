# PH-9 / T2 红证：跨源剥头

```text
baseline: c3ffc37
命令: cc -I <baseline shim> -I test/fixtures test/fixtures/p9-cross-host.c \
      test/fixtures/p9-server.c <baseline shim.c> -lcurl -o /tmp/p9-cross-host
      /tmp/p9-cross-host
原始输出:
cross auth 0 cookie 0 proxy 0 status 200
cross referer 0
port auth 0 cookie 0 proxy 0 status 200
same auth 0 cookie 0 proxy 0 status 200
same referer 0
退出码: 0
green: 实现后 `bash test/run.sh p9-cross-host` 退出 0，夹具输出
`cross auth 0 cookie 0 proxy 0 status 200`、`cross referer 0`、
`port auth 0 cookie 0 proxy 0 status 200`、
`same auth 1 cookie 1 proxy 1 status 200`、`same referer 1`
```

基线的 shim 从未把请求头交给 libcurl（`CURLOPT_HTTPHEADER` 没有被设置），所以四个头
一个都没发出去：三条 `cross` 断言是**空过**，真正红的是同源行的
`same auth 0 cookie 0 proxy 0` 与 `same referer 0`——实现后同源必须保留（变 1），
跨源必须剥离（保持 0）。只测跨源会漏掉「根本没发头」这种假绿，所以同源行是必要的对照。

跨源覆盖两个轴：

- host：`127.0.0.1` → `localhost`（同端口）；
- port：`127.0.0.1:PA` → `127.0.0.1:PB`（同主机）。

`127.0.0.2` 在本机 macOS 不可 bind（`errno 49`），所以 host 轴改用 `localhost` 别名，
指向同一台机器的另一个主机名，仍是真实的 origin 变化。
