# PH7-T2 红证：回调中止

- baseline: `178719f`（PH7-T1 流式分片）
- 夹具: `p7-abort.c` + expected
- 目的: 首片回调返回非 0 时，传输立即中止；对外 `error()==23`、`is_cancelled()==0`，
  响应不持有 body，已交付的首片计入 `total_bytes`。

## 红

```console
$ bash test/run.sh p7-abort
--- expected
+++ actual
@@ -1 +1 @@

+error 0 cancelled 0 body_len 0 body_null 1 total_gt0 1 chunks 68
FAIL p7-abort: output mismatch
rc=1
```

行为红：T1 调用了回调但忽略返回值，1 MB 流继续读完，回调被调用 68 次。
