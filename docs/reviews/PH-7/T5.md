# PH7-T5 红证：流式状态校验

- baseline: `cd93f0a`（PH7-T4 流式空闲）
- 夹具: `p7-mutex.c` + expected
- 目的: `send_stream` 没有回调时读 `-1001` 且不发请求；同一请求混用 `send()` 与
  `send_stream()` 时第二次读 `-1007` 且不再发请求。

## 红

```console
$ bash test/run.sh p7-mutex
--- expected
+++ actual
@@ -1,2 +1,2 @@
-nullcb -1001 requests 0
-mixed -1007 requests 1
+nullcb 0 requests 1
+mixed 0 requests 3
FAIL p7-mutex: output mismatch
rc=1
```

行为红：NULL 回调被当成“只计数不交付”，请求真的发了出去；混用两种模式也没有拦截，
三次调用都到达服务端（计数 3）。

## 转绿

```console
$ bash test/run.sh p7-mutex
ok p7-mutex
rc=0
```

green: 输出 `nullcb -1001 requests 0`、`mixed -1007 requests 1`。转绿提交 sha 见
`docs/phases/PH-7/closeout.md` §2。
