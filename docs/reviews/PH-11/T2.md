# PH-11 T2 红证：applies-to 全量同步

- baseline: `937c05d`
- verify：`grep -rh '^- applies-to:' README.md docs --include='*.md' | sort -u` 与
  `bash tools/check.sh g4`

## 红（基线复跑）

```console
$ grep -rh '^- applies-to:' README.md docs --include='*.md' | sort | uniq -c
  19 - applies-to: 0.1.0
退出码: 0
```

基线 19 个用户面文档全部指向 `0.1.0`，与新版本落点不一致；`g4-applies` 会以
`applies-to=0.1.0, release anchor=0.2.0` 拒绝。

## 绿（实现后复跑）

```console
$ grep -rl '^- applies-to: 0.2.0' README.md docs --include='*.md' | wc -l
19
退出码: 0
$ grep -rh '^- applies-to:' README.md docs --include='*.md' | sort -u
- applies-to: 0.2.0
退出码: 0
```

```console
$ bash tools/check.sh g4
note g4-version: PATCH accounting deferred by deviation V-001 (0.1.0 number line)
ok g4 (132 docs <= 300 lines, 8 snippets compiled, 13 blocks bound, anchors/applies/readme/version ok)
退出码: 0
```

green：19 个文件（README、设计、需求、验收映射、会话地图、流式、勘误、两份 planning、
10 篇教程）全部为 `0.2.0`，`g4` 的应用面检查通过。
说明：`g4-version` 的 `note` 是门禁固定文案（`d ≠ 0` 时打印），未改门禁。
