# PH-11 T1 红证：编译器下限与能力依据

- baseline: `937c05d`
- verify：`grep -c 'requires = ct >= 0.53.1' ct.pkg` 与
  `CT_BIN=/tmp/ct-bin-0531/ct bash test/gates/p10_install.sh`

## 红（基线复跑）

```console
$ grep -c 'requires = ct >= 0.53.1' ct.pkg
0
退出码: 1
```

基线写的是 `requires = ct >= 0.34.0`，理由为 `impl T { static T *new(); }`（Phase 34）。
该理由对本包已不成立：公开面是 `pub trait` + `map trait`，静态固有方法无任何调用点。

```console
$ grep -rn 'impl ' http/
退出码: 1
```

能力对照（同一安装样例，换编译器）：

```console
$ CT_BIN=/Users/samxx/.local/bin/ct-v0.49.0.bak bash test/gates/p10_install.sh
ct-ast build -I vendor/http --ldflags '-lcurl' sample.ct -o build
FAIL p10_install: ct install printed no build command
退出码: 1
```

## 绿（实现后复跑）

```console
$ grep -c 'requires = ct >= 0.53.1' ct.pkg
1
退出码: 0
$ grep -rn 'ct >= 0.34.0\|ct v0.44.1' ct.pkg docs/design.md docs/requirements.md docs/phases/H1.md README.md
退出码: 1
```

```console
$ CT_BIN=/tmp/ct-bin-0531/ct bash test/gates/p10_install.sh
install ok
200
退出码: 0
```

green：下限抬到 `ct >= 0.53.1`；`ct install` 打印 `ct build -I vendor/http`，
安装样例输出 `200`。反证：低于下限的 `ct v0.53.0` 被 `ct get` 拒绝，原文：

```console
$ CT_BIN=/Users/samxx/.local/bin/ct bash test/gates/p10_install.sh
ctc: package 'http' requires 'ct >= 0.53.1', but this is v0.53.0
ctc: use --force to get anyway
FAIL p10_install: ct get (local dir spec)
退出码: 1
```
