# H1 卡：骨架、构造与 Drop、配置方法

- 状态：草案（2026-11-13），未开工
- phase：H1
- version：0.1.0（首次发布时 tag `v0.1.0`；H1 收口不改 MINOR）
- 依赖：编译器需支持“静态固有方法 + `impl T {}` + `use Drop`”（Phase 34 线，见
  [docs/design.md](../design.md) 第 1 节）
- 前置假设核验：四条已核（design.md §1），其中 D-2（链式不成立）改变了 API 书写方式

## 0. 目标

不用 libcurl 就能编译、运行、可被测试的 `HttpRequest` / `HttpResponse` 值对象：
构造、七个配置方法、`Drop` 占位清理、结果读取面。

**H1 不发起任何网络请求**，也不 `#include <curl/curl.h>`。

## 3. 风险与前置

- **链式不成立**（D-2）：若用户坚持单表达式链，必须改走 `map` 宿主方法（`ct-pkg/curl` 形态），
  本卡全部配置任务重写。等待裁决后再开工 H1-T2。
- **编译器未发布**：静态固有方法在当前 HEAD 可用、发布版不可用；`ct.pkg` 已写
  `requires = ct >= 0.34.0`。
- **目录待收口**（D-1）：单元若加 `namespace http;` 必须迁到 `http/` 目录。
