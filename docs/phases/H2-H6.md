# H2–H6 任务级计划

- 状态：草案（2026-11-13）
- 说明：每项 = 一个交付物 + 一条 `verify` + 一次提交 + 可单独回滚（T-1…T-4）。
  `先红后绿` 为“是”的任务必须先提交失败夹具与红证。

## 依赖顺序

H1 → H2 → H3 → H4 → H5 → H6。H3 依赖 H2 的缓冲与 shim；H4 依赖 H3 的回调路径；
H5 依赖 H2–H4 的真实错误样本；H6 是收口，不引入新能力。
