# PH3-T4 红证：只接受 http(s)

- baseline: 1ed6ecc（PH3-T3 实现）
- 夹具: `test/fixtures/p3-scheme.c` + `p3-scheme.expected.out`
- 目的: `file://` / `ftp://` 在工厂返回时就带本地负数码，`http` / `HTTPS`（大小写不敏感）为 0。

## 红

```console
$ bash test/run.sh p3-scheme
--- test/fixtures/p3-scheme.expected.out
+++ .../p3-scheme.out
@@ -1 +1 @@
-file -1004 ftp -1004 http 0 https 0
+file 0 ftp 0 http 0 https 0
FAIL p3-scheme: output mismatch
rc=1
```

## 转绿

实现提交 `feat(http): PH3-T4 协议白名单` 后：

```console
$ bash test/run.sh p3-scheme
ok p3-scheme
rc=0
```

green: `bash test/run.sh p3-scheme` 退出 0。
